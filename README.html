# Chloha Damage Lab — Community Edition

**最終固定版：v1.0.0 Stable / オーナー・所属コミュニティ向け完成品**

完成版ZIPはオーナー本人と所属コミュニティメンバーへの限定配布です。一般向けオープンソース配布は行いません。Web公開とコミュニティ限定配布を分け、数値・識別名・自作コード・上流ライセンスを個別評価しました。計算に不要な外部参照メタデータ、画像等は除外しています。`LICENSE`、`THIRD-PARTY-NOTICES.md`、`INDIVIDUAL-RIGHTS-REVIEW.md`を確認してください。

## 何ができる？

ブラウザで使うポケモンのダメージ計算機です。373件のポケモン・フォーム、335件の技を含むv1.0.0の登録範囲を保存します。登録されていることと、実機確認済み・収録確定・全条件対応であることは別です。画面の未対応・部分対応・未検証表示を確認してください。

対応言語：日本語、英語、フランス語、ドイツ語、スペイン語、イタリア語、韓国語、中国語簡体字、中国語繁体字。ES-LAは含めません。

現在の製品は[Singularity](https://kurohanolu.github.io/singularity/)です。この旧製品は最終版を固定保存し、今後の更新を自動取得しません。最新環境との完全互換性は保証しません。自動転送もしません。

## 限定配布と起動

オーナーが所属メンバーだけアクセスできるチャンネル等で `Chloha-Damage-Lab-v1.0.0-Community-Edition.zip` を提供します。旧サイトにZIPの取得リンクを設置せず、公開GitHub Releaseにも置きません。チャンネルの非公開設定と受領者の所属確認は、配布時に別途確認します。単なる「リンクを知っている人全員」の共有は、メンバー限定のアクセス制御とは扱いません。

個人利用・個人改造・コミュニティ内での改造版共有を許可します。コミュニティ外への再配布、改造版の一般公開、商用販売は禁止します。ただし、既存のMIT/BSD等で許諾された部分の権利は維持され、第三者ライセンスを上書きしません。完成品全体を自由に再配布できるという意味ではありません。

既存の`v1.0.0.zip`はSingularityの原本であり、このCommunity Editionの配布物ではありません。Web版は従来URLで公開可能な素材・コードを確認したうえで提供します。URL共有はアクセス制御ではありません。

1. ZIP全体を展開します。HTMLだけを別の場所へ移動しないでください。
2. 展開先の`index.html`をChrome等のブラウザで開きます。計算にビルド・APIキー・ログイン・インターネット接続は不要です。
3. ファイルを直接開く方式では、ブラウザやOSによって入力保存の扱いが異なります。ファイルを移動した場合にも保存が継続するとは限りません。安定した同一オリジンでの利用には、次のローカルサーバーを使います。

Python 3がある場合、展開先で次を実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Windowsで`python3`がない場合は`py -m http.server 8000 --bind 127.0.0.1`を使います。その後、ブラウザで `http://127.0.0.1:8000/` を開いてください。終了はターミナルでCtrl+Cです。スマートフォンのファイル直接起動はOSに制約があるため、Web版の利用を推奨します。

ポケモン画像、Singularity/Tiaraロゴ、外部フォント、非公開フィードバック送信機能は含めません。画像なしでも計算できます。入力条件は元のv1.0.0と同じ保存方式・保存キーを使用します。既存入力を意図的に初期化する処理は加えていません。

たとえば「ピンク・白・ゴールドの可愛いUIにしたい」と追記できます。デザインの主な変更先は`community.css`、見出し等は`community.js`です。Tiaraの公式ロゴやブランド素材を使う場合には、権利者の許可が必要です。本配布はその許可を与えません。

## 改造版を保存・共有する

完成品の公開Forkは配布方法にしません。配布ZIPのコピーをローカルGitや、アクセス先を所属メンバーに制限した非公開の開発環境で管理してください。非公開リポジトリを使う場合も、招待先と公開設定を確認します。公開サイトや公開共有リンクで改造版を配布しないでください。

名前・版番号を独自のものへ変更し、計算・9言語・保存復元・ZIP展開後の検査を行ってから、所属コミュニティ内でのみ共有します。Tiara等の公式版だと誤認させる表記は避けてください。

現在の`audit/chloha-community-preparation`はデータを含まない監査ツールのみです。完成版ソースの公開先ではありません。既存のmainや`v1.0.0`タグの内容・許諾をこの方針変更で書き換えません。

## 開発者向け再構成

ZIP内のアプリは静的ファイル一式です。利用やCSS編集にnpmは不要です。同じ同じ固定版を作り直す場合は、全Git履歴を持つv1.0.0の作業コピーを用意し、監査ブランチからcommunity、scripts/community、tests/communityをコピーした後、次を実行します。これはローカル検証であり再配布の許可ではありません。

```sh
python3 scripts/community/build.py --review-only
node tests/community/package.cjs
node tests/community/browser.cjs
```

ブラウザテストにはプロジェクトのPlaywright依存とChromiumが必要です。`--review-only`は権利確認の未完了を解消しません。ZIPとそのハッシュは`dist/community/private/`、Web用のアプリと文書は`dist/community/site/`へ分けて出力します。両者のアプリ本体は同一です。`dist/community`全体をWebに配置してはいけません。

提供範囲ごとの権利判定は別途 `node scripts/community/publication-gate.cjs --scope publicWeb` と `node scripts/community/publication-gate.cjs --scope communityZip` で行います。一方の判断を他方に流用せず、各ファイルのハッシュ・分類・理由・通知を証拠と照合します。変更した派生版では変更箇所を再評価し、独自の証拠を作成します。元の固定版の証拠は書き換えません。一般向けZIP配布は方針上の対象外です。

## 計算精度を再検証する

元のv1.0.0の検証結果を基準に、最小／最大ダメージ、16乱数、割合、KO、タイプ、天候・フィールド、特性、持ち物、条件付き威力、連続技、メガシンカ、防御補正を比較します。最低限、次を維持してください。

```sh
node tests/v100-engine-promotion.cjs
node tests/v0184-public-baseline.cjs
node tests/showdown-compare.mjs
node tests/showdown-differential.mjs
node tests/community/package.cjs
node tests/community/browser.cjs
```

変更前の数値を、変更後の出力で上書きして期待値にしてはいけません。コミュニティ版の計算エンジン・計算用の登録値・翻訳は原本から固定し、復旧用と配布用で同じアプリを使用します。未使用の監査メタデータは除き、行順は当アプリのID順へ整理しています。配布物の`application-manifest.json`がアプリファイル単位とアプリ全体のSHA-256を、ZIP横の`.sha256`が文書を含むZIP全体のSHA-256を記録します。

## 既知の制限

- 全ポケモン・技・特性への完全対応ではありません。レイジングブルの壁破壊、一部連続技とマルチスケイル等の未対応範囲は原本と同じです。
- Pokémon Champions全実機仕様との一致を保証しません。Showdown比較とゲーム実機の観測は別です。過去の実機観測記録も入力不足のものは合格証拠にしません。
- 種族値・特性・収録候補には未検証項目が残ります。原本監査で、ノココッチの特攻種族値は原本の58と現在のShowdownの85で相違を確認しました。最終固定版の数値を勝手に変更せず、原本の既知の不整合として開示します。
- 保存にはブラウザの保存権限と容量が必要です。30日の有効期間、私用モード等による制約は元の実装どおりです。
- Chromiumの自動ブラウザ検査は、Android/iOSの実機操作・全ブラウザ・全翻訳の専門家校閲の代わりにはなりません。
- URLを知っていれば誰でもアクセスできる公開方式です。限定共有はアクセス制御ではありません。
