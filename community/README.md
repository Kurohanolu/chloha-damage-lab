# Chloha Damage Lab — Community Edition

**最終固定対象：v1.0.0 Stable / 現在は公開前の検証候補**

第三者データの再配布条件に未解決事項があるため、現時点では完成版ZIPの一般配布・本番公開をしていません。このREADMEは候補の検証と、条件を満たした後の利用に向けたガイドです。`THIRD-PARTY-NOTICES.md`を先に確認してください。

## 何ができる？

ブラウザで使うポケモンのダメージ計算機です。373件のポケモン・フォーム、335件の技を含むv1.0.0の登録範囲を保存します。登録されていることと、実機確認済み・収録確定・全条件対応であることは別です。画面の未対応・部分対応・未検証表示を確認してください。

対応言語：日本語、英語、フランス語、ドイツ語、スペイン語、イタリア語、韓国語、中国語簡体字、中国語繁体字。ES-LAは含めません。

現在の製品は[Singularity](https://kurohanolu.github.io/singularity/)です。この旧製品は最終版を固定保存し、今後の更新を自動取得しません。最新環境との完全互換性は保証しません。自動転送もしません。

## ダウンロードと起動

公開条件を満たした後は、旧サイトまたは専用GitHub Releaseから `Chloha-Damage-Lab-v1.0.0-Community-Edition.zip` を取得する構成です。**現時点では公開済みダウンロード先はありません。** 既存の`v1.0.0.zip`はSingularityの原本であり、このCommunity Editionの配布物ではありません。

1. ZIP全体を展開します。HTMLだけを別の場所へ移動しないでください。
2. 展開先の`index.html`をChrome等のブラウザで開きます。計算にビルド・APIキー・ログイン・インターネット接続は不要です。
3. ファイルを直接開く方式では、ブラウザやOSによって入力保存の扱いが異なります。ファイルを移動した場合にも保存が継続するとは限りません。安定した同一オリジンでの利用には、次のローカルサーバーを使います。

Python 3がある場合、展開先で次を実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Windowsで`python3`がない場合は`py -m http.server 8000 --bind 127.0.0.1`を使います。その後、ブラウザで `http://127.0.0.1:8000/` を開いてください。終了はターミナルでCtrl+Cです。スマートフォンのファイル直接起動はOSに制約があるため、公開後はWeb版の利用を推奨します。

ポケモン画像、Singularity/Tiaraロゴ、外部フォント、非公開フィードバック送信機能は含めません。画像なしでも計算できます。入力条件は元のv1.0.0と同じ保存方式・保存キーを使用します。既存入力を意図的に初期化する処理は加えていません。

## ChatGPTで自分用に改造する

原本ZIPを別名で保管し、展開したフォルダをコピーしてから作業します。ファイルをChatGPTや開発環境へ読み込ませ、次の指示をコピーしてください。

> このChloha Damage Labを自分専用に改造してください。
>
> 計算エンジンとポケモンデータは変更せず、UIデザインを自分好みに変更したいです。
>
> 既存の計算機能と多言語対応を維持してください。
>
> 修正後は動作確認と回帰テストを実施してください。
>
> 元のv1.0.0 Stableは変更せず、派生版として保存してください。
>
> 第三者素材の利用条件を確認し、公開停止条件が残っていれば公開しないでください。

たとえば「ピンク・白・ゴールドの可愛いUIにしたい」と追記できます。デザインの主な変更先は`community.css`、見出し等は`community.js`です。Tiaraの公式ロゴやブランド素材を使う場合には、権利者の許可が必要です。本配布はその許可を与えません。

## 開発者向け再構成

ローカル検証用ZIP内のアプリは静的ファイル一式です。利用やCSS編集にnpmは不要です。同じ候補を作り直す場合は、全Git履歴を持つv1.0.0の作業コピーを用意し、監査ブランチからcommunity、scripts/community、tests/communityをコピーした後、次を実行します。これはローカル検証であり再配布の許可ではありません。

```sh
python3 scripts/community/build.py --review-only
node tests/community/package.cjs
node tests/community/browser.cjs
```

ブラウザテストにはプロジェクトのPlaywright依存とChromiumが必要です。`--review-only`は権利確認の未完了を解消しません。公開判定は別途 `node scripts/community/publication-gate.cjs` で行い、未解決事項がある間は必ず失敗します。

## 計算精度を再検証する

元のv1.0.0の検証結果を基準に、最小／最大ダメージ、16乱数、割合、KO、タイプ、天候・フィールド、特性、持ち物、条件付き威力、連続技、メガシンカ、防御補正を比較します。最低限、次を維持してください。

```sh
node tests/v100-engine-promotion.cjs
node tests/v0184-public-baseline.cjs
node tests/showdown-compare.mjs
node tests/showdown-differential.mjs
node tests/community/package.cjs
node tests/community/browser.cjs
```

変更前の数値を、変更後の出力で上書きして期待値にしてはいけません。コミュニティ版の計算エンジン・データ・翻訳は原本から固定し、復旧用と配布用で同じアプリを使用します。配布物の`application-manifest.json`がアプリファイル単位とアプリ全体のSHA-256を、ZIP横の`.sha256`が文書を含むZIP全体のSHA-256を記録します。

## 既知の制限

- 全ポケモン・技・特性への完全対応ではありません。レイジングブルの壁破壊、一部連続技とマルチスケイル等の未対応範囲は原本と同じです。
- Pokémon Champions全実機仕様との一致を保証しません。Showdown比較とゲーム実機の観測は別です。過去の実機観測記録も入力不足のものは合格証拠にしません。
- 種族値・特性・収録候補には未検証項目が残ります。今回、ノココッチの特攻種族値は原本の58と現在のShowdownの85で相違を確認しました。最終固定版の数値を勝手に変更せず、原本の既知の不整合として開示します。
- 保存にはブラウザの保存権限と容量が必要です。30日の有効期間、私用モード等による制約は元の実装どおりです。
- Chromiumの自動ブラウザ検査は、Android/iOSの実機操作・全ブラウザ・全翻訳の専門家校閲の代わりにはなりません。
- URLを知っていれば誰でもアクセスできる公開方式です。限定共有はアクセス制御ではありません。
