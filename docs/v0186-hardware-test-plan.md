## 共通の記録

ゲーム版・更新番号・検証日・ルール、双方の正確なポケモン／形態、レベル、タイプ、特性、持ち物、6能力ポイント・性格補正・実数値、攻撃前HPと最大HP、双方ランク、技、天候・フィールド・接地、壁・味方支援・急所・その他発動条件を記録する。分からない項目は不明とし、推測で埋めない。

ダメージは攻撃前後のHP差を優先し、回復・定数ダメージ・連続技の途中変化が入った場合は個別に記録する。個人名、アカウントID、メールや対戦相手の識別情報は不要。動画や画像は必要なバトル画面／能力画面だけを残す。

## サンプリングと判定

- 単発1回で16乱数すべての再現を主張しない。観測値が予測集合外なら、まず入力・個体条件・別効果を再確認する。
- 丸め差の試験は、修正前後で予測集合が異なる条件を先に選ぶ。予測が同じ条件で「丸めも検証済み」としない。
- 有限回の測定で未観測の乱数があることだけを不一致としない。連続技はダメージ乱数とヒット数・命中を分けて扱う。
- 各試験を `未実施 / 条件不足 / 一致を観測 / 不一致を観測 / 再現確認済み` で管理し、証拠・回数・残る曖昧さを明記する。
- 資料と食い違っても、根拠が足りなければ値を変更しない。既知の重大な誤計算が残る場合はCI成功でも公開を認めない。
