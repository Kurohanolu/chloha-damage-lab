# v0.188 public asset audit procedure

The v0.188 candidate is not published. Its content must not be expected to match the protected production v0.187 site. The production integrity audit therefore fixes source commit `7210be99c39d75b49ea8200aad91d75801eb300a`, creates an isolated local checkout, and uses that commit's static-site builder. It does not read the moving working tree for expected content.

Run the offline audit-helper tests:

```sh
python3 tests/v0188-asset-audit-test.py
```

Run the read-only production audit:

```sh
python3 scripts/v0188-audit-public-assets.py --external-sprites
```

The JSON evidence is saved to `reports/v0188/public-assets-v0187.json`. The checker uses public GET requests only and no credentials. It performs no deployment, GitHub issue creation, DB update, or Cloudflare settings mutation.

## Verification scope

- Rebuild the full new-site and preserved legacy-site inventories from the exact immutable v0.187 commit in an isolated local checkout.
- Validate the generated files against the builder's manifest.
- Fetch and SHA-256-compare each packaged public file at its bare URL, a cache-busting URL, and every matching versioned URL referenced by the HTML. This covers HTML, JavaScript, external CSS, brand reference/logo/header images, favicon, apple-touch icon, release metadata, and the packaged design preview.
- Treat `.nojekyll` as build metadata rather than an application asset. It is separately recorded, not falsely reported as an HTTP-tested public resource.
- Read embedded sprite data URIs and record decoded hashes. Their source equivalence follows from the checked HTML bytes.
- Inventory all runtime PokeAPI sprite URLs. With `--external-sprites`, fetch each and record HTTP status, actual SHA-256, and byte count.
- Download the actual GitHub Release ZIP and `.sha256` file. Compare the checksum, exact archive bytes generated by `TZ=UTC git archive`, all non-directory entry names/content, and the archive's source commit comment.

## Dynamic and external resource limitations

Runtime portrait/search images not embedded in the HTML use PokeAPI's mutable `master` branch URLs. The application source does not pin or bundle their bytes. Successful HTTP retrieval and observed hashes establish availability at the audit time, not equality to application-source bytes. The JSON explicitly records `sourceMatchEstablished: false` for such observations. Turnstile and the private feedback service are live external dependencies; their response content is not a static release artifact and is audited separately. This checker makes no feedback submission.

The application does not declare a web app manifest in its audited HTML. The generated migration artifact manifest is a local build inventory, not a deployed application manifest. Cache checks here compare exact asset URLs and fresh requests; they do not establish behavior of every browser's already-cached copy.

The v0.188 candidate's generated artifact inventory is supplied by its build/CI evidence; a production comparison of v0.188 is intentionally deferred until independent audit and owner approval authorize publication.
