# Singularity v1.1.0 Pre-Release 4

The language selector now uses the same compact three-column header for all ten languages. The cause was an ES-LA-only mobile CSS rule that moved the selector onto a full-width second row. Removing that special layout and using a bounded 90px native selector preserves the existing accessible control and `ES-LA` label.

Regression coverage measures geometry at 320, 360, 375, 390, 412, 430 and 768 pixels; exercises Japanese/ES-LA, English/ES-LA and Spanish/ES-LA roundtrips; reloads saved ES-LA; and recalculates in Spanish before returning to Japanese. The same browser test runs against the public URL after deployment. Chromium mobile emulation is browser evidence, not physical-device certification.

The numerical engine, Pokémon data, move/item/ability mechanics, internal `es-LA`, browser `es-419`, persistence schema and translation dictionaries are unchanged from pre.3. Existing ten-language numerical and UI suites remain required. The original nine feedback languages remain available, ES-LA report submission remains paused, and existing terminology fallback limitations remain in force.

This distinct prerelease preserves immutable pre.3 and requires its own exact-source CI, independent 6.1 Sol review, owner decision binding, deployment provenance and public acceptance receipts. The owner has authorized publication after these conditions pass. No existing release receipt grants approval to the pending candidate.
