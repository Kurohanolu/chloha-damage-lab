# Chloha Damage Lab v0.184 Pre-Release 29

This release completes the v0.184 engine-extraction iteration. Existing damage formulas, move data, item/ability acceptance, translations, and known unsupported conditions are preserved.

- Separate battle, move-mechanic, ability, and validation reference data from the calculation engine.
- Isolate calculation internals while preserving `window.ChlohaDamageEngine` and explicit legacy UI bindings.
- Move Shell Side Arm category selection, Beat Up, and standard/special multi-hit aggregation into a DOM-independent calculator.
- Freeze 300 complete results/errors from the previous public release, including traces, probability distributions, and KO probabilities.
- Run initialization, preservation, Showdown, UI, and nine-language checks before publication. Verify the deployed HTML and JavaScript contents against the published commit.

The existing unsupported multi-hit/Multiscale combinations and defender weather/terrain ability restrictions remain unchanged. Automated reference preservation does not establish additional Pokémon Champions hardware parity.
