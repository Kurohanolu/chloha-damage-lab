# Singularity v1.1.0 Pre-Release 3

Candidate prerelease. Chloha Labs. Prepared: 2026-11-16 (JST).

This candidate addresses language-selector width and text left in the previous language after switching locales. The visible selector initializer now uses the locale registry and its compact `ES-LA` label, including the fallback initializer. The locale identity remains `es-LA` and the browser locale remains `es-419`.

The compact result is now rendered from existing computed numbers, and move/terrain labels in warnings, history and confirmation text come from canonical values. This prevents translated DOM text from becoming the source for a later language change. Calculation inputs and canonical game IDs are unchanged; saved-state compatibility remains part of the required regression checks. No new screenshot evidence or terminology mappings are introduced; the accepted 20-image ES-LA audit and its coverage counts remain in place.

The owner authorized publication of the UI correction. The distinct `v1.1.0-pre.3` identity preserves the issued Pre-Release 2 tag. Local checks passed 4,520 numerical-equivalence comparisons and 300 baseline cases on an uncommitted preview. Fresh CI, independent Sol review, source-bound release evidence and live verification are pending. This document does not claim that the candidate has passed or been published. The issued Pre-Release 2 release and its evidence remain immutable.

ES-LA feedback submission remains temporarily paused; the existing nine languages retain their feedback behavior. The numerical engine, production Worker, database and access protections are outside this change. Original owner screenshots are not distributed.
