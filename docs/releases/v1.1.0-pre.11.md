# Singularity v1.1.0 Pre-Release 11 — Weather validation repair

Defending Drizzle, Drought, Sand Stream and Snow Warning were selectable in the UI
but missing from the engine's defender validation IDs, causing calculation errors.
The shared weather map now supplies the four IDs. Existing weather inference,
damage arithmetic and rounding are unchanged.

Sand boosts Rock SpD and snow boosts Ice Defense according to the defensive stat
actually used by the move, including Psyshock. Hippowdon receives no sand SpD
bonus. Water Spout's HP-based power, all sixteen rolls and KO probabilities are
covered by 2,592 independent arithmetic cases and 1,680 locked Champions Showdown
vectors. The weather browser regression covers 220 cases across ten languages,
saved-state reload and 320/390-pixel mobile views, including both reported Mega
forms and Hippowdon. Existing comprehensive CI remains mandatory.

The original 300 fixtures are unchanged. One erroneous historical defensive
Drizzle rejection has a separate digest-bound numeric correction for Singularity.
Fixed Community and historical browser tests keep their own immutable contracts.
Community Edition, roster, translation dictionaries and feedback backend remain
unchanged. Pre.10 belongs to the separate feedback preparation PR.

Manual weather takes precedence. Conflicting automatic setters retain the
existing attacker-first policy; entry order is not modeled. No unverified roster
or ability is added. Aurorus's current Champions ability remains unconfirmed by
primary evidence; Mega Sol support is outside this repair.
