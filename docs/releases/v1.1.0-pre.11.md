# Singularity v1.1.0 Pre-Release 11 — Weather validation repair

Candidate only. Pre.10 is reserved by the independent feedback preparation PR.

Defending Drizzle, Drought, Sand Stream and Snow Warning were exposed by the UI
but missing from the engine's defender validation IDs. The shared weather map
now supplies these four IDs. Existing weather inference and damage rounding are
unchanged: manual weather overrides automatic inference; automatic conflicts
retain the historical attacker-first policy (entry order is not modeled).

Sand boosts Rock SpD; snow boosts Ice Defense, according to the defensive stat
actually used by the move (including Psyshock). Existing modifiers are reused,
never added twice. Water Spout HP and all sixteen random rolls are tested.

The original 300 fixtures remain unchanged; one historical Drizzle rejection
has an explicit correction tied to its original error and a fixed numeric vector.
All previous locale, arithmetic, mobile and publication checks remain required.
New weather tests cover a separate integer oracle, locked Showdown, ten locales,
reload and 320/390-pixel mobile views. The six existing Snow Warning forms are
audited without expanding the roster or changing translation dictionaries.

Community Edition and the feedback service stay pinned. No earlier audit or
publication receipt authorizes this candidate. Release requires exact-head CI
and independent review; no publication is claimed by these notes.
