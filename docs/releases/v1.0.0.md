## 利用環境と9言語

インストール不要のWebアプリです。スマートフォン、タブレット、デスクトップ向けの画面を用意しています。検証はChromiumのブラウザ自動化と320・360・390・430・768・1440pxの画面幅を中心に行います。Android/iOSの全物理端末や、すべてのブラウザ・OSでの動作を保証するものではありません。

日本語、英語、フランス語、ドイツ語、スペイン語、イタリア語、韓国語、中国語簡体字、中国語繁体字に対応します。翻訳名検索、言語切替、再読み込み時の言語・入力復元を提供します。全文章の専門家による校閲完了を意味しません。

## 計算と入力保存

対応している技・特性・持ち物、タイプ相性、能力値とランク、急所、天候・フィールド、壁・軽減などの条件から、16段階の乱数を含むダメージを計算します。対応する威力変動技、体重依存技、連続技にも計算方式を設けています。技ごとの未対応・部分対応・未検証表示を確認してください。

計算条件を端末のブラウザへ保存し、再読み込み時に復元します。有効期間は30日です。初期化できます。保存拒否や容量制限がある環境では保存できない場合があります。フィードバック本文・連絡先・認証情報・非公開スナップショットは、この計算条件の自動保存対象に含みません。

## 匿名フィードバック

画面内のフィードバックから、不具合、計算結果、翻訳、機能要望を報告できます。連絡先は任意です。計算条件の添付は任意で、送信前に内容を確認・同意します。計算条件または数値結果が変わると、以前の添付同意は失効します。

報告は非公開で受け付け、管理者認証とTurnstileを維持します。GitHub Issueへの転記は、承認された技術情報だけに限定します。送信前に個人情報・認証情報を本文へ含めていないか確認してください。

既存APIとの互換性のため、この正式版だけは通信上の版番号を`v1.0`へ明示的に対応付け、完全な`v1.0.0`を送信前の表示と報告本文の固定メタデータに保持します。データベースの版番号欄だけではパッチ版を識別せず、完全な版番号は報告本文にも記録します。将来のパッチ版へ自動的に流用する対応ではありません。

## 既知の制限

- 全ポケモン・全技・全特性への完全対応ではありません。レイジングブルの壁破壊、一部の連続技とマルチスケイル等、未対応・部分対応条件を残します。
- Pokémon Championsの全実機仕様との完全一致を保証しません。確認済みの差異と未検証仕様を区別し、Showdownとの一致を実機一致とは扱いません。
- 一部の種族値・技・特性の参照データに未検証項目があります。対象外のルールや今後の採用時には再検証が必要です。
- Cloudflareの公開側の保護は検証しますが、最新の認証済み管理設定・D1の内部状態・完全な本番コード同定・バックエンド復旧実行は未検証の範囲を残します。
- 物理端末、ネイティブスクリーンリーダー、OS IME、全配色・全翻訳の網羅的な検証は完了していません。
- 有限時間のGC・反復操作検査は、長時間の全メモリ動作や、将来の不具合が存在しないことを保証しません。
- 外部スプライトは外部提供元の稼働に依存します。

不具合は画面内のフィードバックから報告してください。競技に重要な境界条件や未検証項目では、表示される対応範囲と条件を確認してください。正式版であっても、これらの制限は継続して開示・改善します。
