# Singularity v1.1.0 Pre-Release 14

Last Respects and Rage Fist gain count buttons beside the move picker, using the existing engine and persisted inputs. Last Respects exposes 0–5 fainted allies (50–300 power); Rage Fist exposes 0–6+ successful hits (50–350 power). Existing saved hit counts above six remain preserved. Ten-language copy reuses canonical move names and applied-power wording. Spit Up buttons wrap at narrow widths.

Publication requires independent review, all required exact-source CI and actual public-site acceptance. No Community Edition changes are authorized.
