# Singularity v1.1.0 Pre-Release 1

Public prerelease. Chloha Labs.

Release date: 2026-11-16 (JST).

Adds Latin American Spanish as the tenth selectable language, preserving Spain Spanish and the previous nine-language behavior. Regional game terminology is linked to canonical IDs and documented sources; unverified terms use explicitly disclosed fallbacks. Translation coverage and official confirmation rates are reported separately in `docs/v110-es-la-translation-coverage.md`.

The numerical engine, saved calculation settings and anonymous feedback protections are preserved. Development verification includes ten-language switching/search/reload/result consistency, the original nine-language regression suite and comparison with the audited Stable numerical baseline.

Known limitations include incomplete official ES-LA game terminology confirmation, physical devices/native assistive technology and OS IME, and existing partial/unverified Champions mechanics. This candidate does not claim complete game coverage or complete hardware verification.

ES-LA feedback submission is temporarily paused because the production validator could not be updated. A visible Spanish notice explains the pause; switching to one of the existing nine languages restores the form. Calculation, search, saved state and ten-language display remain available. The production Worker, access protections and database are unchanged. The owner explicitly selected this reduced feedback scope.

Report problems using the anonymous feedback form in one of the existing nine languages. No production test reports are created by the development checks.
