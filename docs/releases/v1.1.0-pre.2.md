# Singularity v1.1.0 Pre-Release 2

Public prerelease. Chloha Labs.

Release date: 2026-11-16 (JST).

Improves Latin American Spanish terminology using 20 privately reviewed Pokémon Champions screenshots. Official Champions confirmation increases from 112 to 142 of 1,029 registered names; unverified fallback names decrease from 739 to 714. Regional names remain tied to existing canonical IDs. Abbreviations, form labels and game effect descriptions retain their own evidence scope.

Corrects the capitalization of Firme and supports the joined Floette Flor Eterna search alias while retaining the existing form display and IDs. Search aliases preserve Spain Spanish and existing names. The numerical engine, registered game inventory, saved settings and other nine language dictionaries are unchanged.

The exact Pre-Release 2 candidate (95e61b419f7e348fe5ec59b4355692bf81f335a6) passed all 13 CI workflows and 18 ES-LA acceptance tests, including 4,520 complete numerical comparisons with no differences, 110 language transitions, 15 reloads, 60 mobile viewport cases and the existing nine-language regressions. The new release has its own independent Sol review and source-bound owner approval; publication additionally checks the actual deployed files.

Official ES-LA terminology coverage remains incomplete. Unverified names use disclosed fallbacks; the audit does not certify exhaustive native-language quality, physical-device behavior or every Champions mechanic. Original owner screenshots are not distributed.

ES-LA feedback submission remains temporarily paused. Switching to one of the existing nine languages restores the form. Reports record Pre-Release 2 through the established compatible wire format. The production Worker, database and access protections are unchanged. No production test reports are submitted.
