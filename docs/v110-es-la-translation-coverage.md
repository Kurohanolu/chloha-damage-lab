## Meaning of the counts

Names are tied to existing canonical IDs. `official` means the exact spelling is attested in an official publication for the stated game (Champions or Z-A), not that a physical game test was performed. The final column separately counts official Champions evidence; the same counts and percentages are preserved in the JSON. `verified-secondary` means a named third-party source attests it for the stated game; Z-A evidence does not establish Champions correctness. Existing ES-ES/English fallback remains `unverified`. No omitted Pokéxperto term is counted as agreement. General UI wording is authored software copy and is not game terminology.

The UI denominator is 391 enumerated phrase/template sites; the warning/error denominator is its 56 flagged sites. These authored or explicitly reused software phrases are provisional, not official game translations. Dynamic function-local template families outside this inventory are a stated coverage limitation and are exercised by browser tests. UI and warning counts overlap and are not semantic-key totals.

Every inventoried name has a display fallback. That display availability is **not** ES-LA translation completion. The form category overlaps Pokémon records. Items count actual supported identities, not thousands of unrelated entries in the upstream name cache. Generic no-item/automatic-berry controls belong to UI.

## Traceable inventory

The complete unresolved list (canonical ID, Japanese, ES-ES, displayed candidate, reason and location to check) is in [v110-es-la-coverage.json](data/v110-es-la-coverage.json). The same file records which source records mapped to runtime identities and which did not. [Source records](data/v110-es-la-source-records.json) preserve the source URLs, dates, target game and independent numeric namespaces.

Selection priority for the same canonical identity is official Champions, explicit secondary Champions, official Z-A, then secondary Z-A. Newer game-specific Champions terminology can differ from Z-A even when the latter is official. Conflicting spellings at the chosen evidence level fail the generator. An explicit canonical English identity must match even when the ES-ES spelling happens to agree; a translated label cannot override a known identity mismatch. Searches may retain both regional spellings as aliases; translated strings never become calculation IDs.

## Remaining limitations

The current source collection cannot establish every registered term as official Champions ES-LA. Unverified fallback is explicitly disclosed in the ES-LA product notice. Formal release needs the owner to judge the documented remaining scope. Existing nine-language dictionaries and calculation data are not modified by this generated name layer.
