## Meaning of the counts

Names are tied to existing canonical IDs. `official` means the exact spelling is attested in official material within the stated scope (Champions, Z-A, or the generic official Pokémon franchise), including visually reviewed owner-provided game captures. Capture evidence verifies visible system wording only; it does not establish damage accuracy, mechanics support or physical-device testing of this calculator. The final column separately counts official Champions evidence; the same counts and percentages are preserved in the JSON. `verified-secondary` means a named third-party source attests it for the stated game; Z-A evidence does not establish Champions correctness. Existing ES-ES/English fallback remains `unverified`. No omitted Pokéxperto term is counted as agreement. General UI wording is authored software copy and is not game terminology.

## Traceable inventory

The complete unresolved list (canonical ID, Japanese, ES-ES, displayed candidate, reason and location to check) is in [v110-es-la-coverage.json](data/v110-es-la-coverage.json). The same file records selected source records and unselected records. For compatibility, the latter remain under unmatchedSourceRecords, with canonicalMatches and selectionReason distinguishing lower-priority evidence from actual missing runtime identities. [Source records](data/v110-es-la-source-records.json) preserve the source URLs, dates, target game and independent numeric namespaces.

Selection priority for the same canonical identity is official Champions, explicit secondary Champions, official non-Champions material, then secondary Z-A. Generic franchise spelling evidence is explicitly labeled Generic Pokémon franchise and never counts as Champions verification. Explicit owner-selected provisional names rank below every verified source and above an unverified fallback; they remain provisional and never count as official or independently attested. Newer game-specific Champions terminology can differ from Z-A even when the latter is official. Conflicting spellings at the chosen evidence level fail the generator, except exact case-only variants; the observed game-field case takes precedence over prose case. Abbreviation-only attestations remain separate from full display-name evidence. An explicit canonical English identity must match even when the ES-ES spelling happens to agree; a translated label cannot override a known identity mismatch. Searches may retain both regional spellings as aliases; translated strings never become calculation IDs.
