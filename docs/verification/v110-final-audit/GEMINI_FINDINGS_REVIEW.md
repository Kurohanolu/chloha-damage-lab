# Gemini指摘の再検証
アナライズは既存UIが発動済みの指定と明記し、既存アダプターのabilityOnも発動状態を明示する。指定参照で行動順・交代・発動フラグ8通りを実行し、発動済みと未発動の入力を分けて全乱数を比較した。天候無効のノーてんき・エアロックは参照側が場の天候を消去するが、現在の攻撃側ドロップダウンの対応能力一覧にない。人工的にIDを挿入すると製品は入力を拒否する。8通りおよび2つの非対応境界をinput-contract.jsonに保存した。
世代混在と参照版の差はREFERENCE_ENGINE_AUDIT.md、オーバーフローはOVERFLOW_AUDIT.mdに記録。元監査が扱わなかったじならしの地形補正は固定SHAで再現し、修正後に同一サンプルを再走した。
