# Champions 実機の高ダメージ挙動

v1.1.0 の整数演算の受入基準は Showdown Champions のコミット abdce0c64597284c8c463b7f71a38dc4dc55cd10 とする。旧監査時点の数値は overflow.json、ko-discriminator.json、signed-hp-witness.json、experiments/ に保存している。

2026年10月の公開映像では、極端な条件のつけあがるで対象のHPが回復したと報告されている。正確なゲームビルド、乱数、各段階の内部整数値は未確認。独立算術の符号付き32ビット予測は実測値ではない。参照エンジンはここで正のダメージを返す。

再検証時はゲームのバージョン、ルール、技、能力、道具、場の状態、直前の正確なHPを記録する。各試行でゲージと攻撃後の数値HP、可能なら次の行動時の実際のHPを採取し、表示だけの変動と区別する。符号境界の前後、通常域の対照、同一条件での反復を含める。ビルドと再現手順が確定し、競合する整数モデルを区別できた段階で仕様変更を別途審査する。
