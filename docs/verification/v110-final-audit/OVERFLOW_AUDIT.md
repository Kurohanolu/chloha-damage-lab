# 高ダメージとHPの未解決事項
実装は対象をレベル50に制限し、手入力の威力は500、攻撃・防御は9999まで受理する。能力依存技の実効威力は別に算出する。指定参照の util.ts はランク補正途中の16ビット化、基礎式・乱数・補正積の32ビット化、最終16ビット化を行う。chainMods はビットシフトしてから上下限を適用する。Singularity は数値を通常の整数として扱い、固定小数点補正値を制限する。実行可能な手入力は対戦での実現可能性を意味しない。

実数値・種族を参照データから作ったサーナイト対オオニューラで、アシストパワーの能力ランク、急所、てだすけ、サイコフィールド、いのちのたまを組み合わせた32条件中13件・186点に差。残りの手入力30件中20件・320点に差。合計62件・992点中、33件・506点の差。大きな乱数ほど大きなダメージになる保証は参照側にない。実際のターン列と技習得・ルール合法性の独立確認は保留。比較失敗をCIの失敗として残す。

2026年10月のDaWoblefetのゲーム映像では、極端な攻撃で対象のHPが回復する。テツポンドの実験2の入力から独立した整数演算で比較した。最低乱数における最終補正積は2,150,301,696。符号付き32ビットとして割り戻すと−523,600、指定参照のgetFinalDamageは688。16個の計算は signed-hp-witness.json に記録した。公開映像の観測は回復方向であり、全16個の符号付き予測値や現在版の内部変数を直接観測したものではない。この実験はメトロノーム等を用いるため、Singularityの対応入力で完全再生したものでもない。

参照にのみ合わせる試作は62件すべてで参照と一致した。比較記録をexperimentsに保存し、この試作をランタイムから外した。最終ログ表示、実際のHP差、乱数およびゲーム版を区別できる対照測定が必要。16ビット境界前後と符号付き32ビット境界前後を別々に測る。HPが1と満タンの両方を使い、KO、生存、回復、ログ表示を同時に記録する。指定参照と同じ算術だけではこの条件は解消しない。
