# Singularity v1.1.0

グラスフィールドで接地した相手への「じならし」の威力と、高ダメージ時の整数演算を修正しました。指定の Showdown Champions 計算エンジンに合わせて、能力ランク、乱数、最終ダメージの各段階でオーバーフローを処理します。乱数が途中で折り返す場合も全16通りから範囲とKO率を計算します。エレキボールとジャイロボールには、同じ参照の素早さ上限と追い風・まひの処理順を適用します。
