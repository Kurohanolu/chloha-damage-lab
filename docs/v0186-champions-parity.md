1. 公式情報。今回のデータ修正では[公式図鑑のメガムクホーク](https://zukan.pokemon.co.jp/detail/0398-1)でかくとう／ひこうを直接確認した。

3. Showdown実装。監査専用に `@smogon/calc@0.12.0`（npm gitHead `d7a69cf40616057ef40faf7623df7a628e58b535`）をlockfileで固定した。**generation 0 = Champions / generation 9 = Gen9** を個別に記録する。公開アプリにこのパッケージは読み込ませない。
4. ポケモンWiki等の仕様資料。
5. 攻略資料。食い違いは推測で上書きしない。

主要な一次実装資料: [Champions計算](https://github.com/smogon/damage-calc/blob/d7a69cf40616057ef40faf7623df7a628e58b535/calc/src/mechanics/champions.ts)、[Gen9計算](https://github.com/smogon/damage-calc/blob/d7a69cf40616057ef40faf7623df7a628e58b535/calc/src/mechanics/gen789.ts)、[丸め・カテゴリ選択](https://github.com/smogon/damage-calc/blob/d7a69cf40616057ef40faf7623df7a628e58b535/calc/src/mechanics/util.ts)、[PS Championsの技データ](https://github.com/smogon/pokemon-showdown/blob/7e743761cd13cdb361fc0f58eb5a866284894f5b/data/mods/champions/moves.ts)。

## 丸め・適用順序・防御

- 固定小数点補正の合成は4096基準、合成時の0.5は切り上げ、値への適用時の0.5は切り下げ。急所とやけどは所定位置で切り捨てる。威力／実数値／乱数前／STAB・相性／最終補正の層を区別した。
- スナイパー、もらいび、そうだいしょう、アナライズ、味方支援、半減特性等の適用層を独立計算に基づき修正。てんねんと別参照実数値／攻撃前上昇の順序も修正した。
- 連続技の半減きのみ・ファントムガードは最初の有効ヒットのみ。14技×3モード×3防御条件の分布とKO率を照合。マルチスケイルの従来の明示的未対応エラーは維持する。
- 無効判定、複合相性、急所／壁、接触分類、接地に応じた既存フィールド効果を検査。一般の行動シミュレーターとしての全状態遷移は保証しない。

固定シード4,000条件、役割別特性321条件、技別657条件、タグの数値比較2,672条件、連続技126分布、体重2,068条件は独立参照に一致。これらのケース数を「全仕様の検証率」と読み替えない。
