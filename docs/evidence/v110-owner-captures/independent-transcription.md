# Independent review of ten private ES-LA owner captures

All ten local originals were individually inspected using view_image. This review does not depend solely on the implementation owner's transcription. Baseline: `a70b45674c66dcfd7b87321c9f012dd36637c3f2`. No repository or image edits were made.

**Result:** 65 fully readable system-owned names (29 items, 20 moves, 6 abilities, 10 types), of which 41 are registered runtime identities (9 items, 16 moves, 6 abilities, 10 types). Six additional party labels are identity context only, giving 71 unique observed entity labels in total.

**Provenance:** The owner attests Pokémon Champions ES-LA. No language-settings screen is supplied; regional vocabulary is consistent. Treat the source as owner-provided game-UI evidence with owner-attested region, not an independently authenticated device/build/locale setting. No mechanical accuracy or learnset completeness is established by a name screenshot.

**Species:** The six party labels match sprites, types and existing species identities, but editable nicknames/default names are not distinguished. Do not promote them to official ES-LA default-species wording on this evidence alone. Mixed Japanese/English labels in the item-menu party make this caveat material. No additional owner screenshot request is necessary for this conservative disposition.

## Ambiguities, spelling and exclusions

- **Liviano = Unburden / かるわざ / unsupported:かるわざ.** The Sneasler screen selects PELEA/VENENO, and its ability is Liviano. This is not Levitate / ふゆう / levitate, whose existing name is Levitación. Official name evidence must not enable an unsupported ability calculation.
- **Electrocañón = Zap Cannon / でんじほう / gw0169_s032.** It is the Raichu Electric move, visibly 8/8 PP; the existing Spanish canonical row already identifies Zap Cannon. Do not merge with Thunder / かみなり / thunder or infer numerical power/accuracy changes from the name/PP display.
- **Fuerza Psíquica = Psychic / サイコキネシス / psychic.** The Farigiraf screen shows NORMAL/PSÍQUICO and 12/12 PP. Existing Champions secondary evidence agrees with this exact name. It is not Psyshock or Expanding Force.
- **Refleluz = Light Clay / ひかりのねんど.** The fully visible item-list label/icon and existing item catalog agree. It is not Reflect / リフレクター, and it is outside the calculator's current selectable item inventory.
- **Imán** occurs in the item screen, so this attests Magnet / じしゃく only. Existing Spanish also uses Imán for Magnet Pull / じりょく; do not promote that ability from an item row.
- **Baya Hibis = Roseli / ロゼルのみ**, not Occa / オッカのみ (existing Baya Caoca). **Baya Acardo = Shuca / シュカのみ**, while **Baya Pomaro = Chople / ヨプのみ**. Berry icons and existing canonical name rows agree.
- **Baya Drasi is fully visible** in capture32684: its purple berry and entire white row are above the bottom boundary. The *next row below it* is clipped and must be excluded. This distinction resolves the earlier 70-versus-71 observation count. Do not adopt the clipped next item.
- Preserve written accents/case: Pañuelo, Elección, Césped, Citrón, Carbón, Mística, Imán, Afín, Somnífero, Protección, Electrocañón, Psíquica, Liofilización; `Cuerpo a Cuerpo` has lowercase a; `Polvo Plata` has no inserted de; `Aerodactylita` visibly uses y. Type headings are uppercase in the originals, including ELÉCTRICO and PSÍQUICO; preserve observedText even if display uses normal title case.
- Semilla Césped agrees with Grassy Seed/グラスシード by source item context and icon; the old ES-ES row says Semilla Hierba. Vidaesfera contrasts with the existing ES-ES Vidasfera. Baya Citrón contrasts with Baya Zidra. Huracán contrasts with Vendaval. Keep ES-ES aliases for independent search, without treating aliases as calculation IDs.
- Raichu is shown carrying Raichunita Y. This does not prove that the displayed species is already Mega Raichu Y or attest a Mega-form label.
- No game item, move, ability, species, type or mechanical identity should be inferred from truncated UI text, unnamed opponent sprites, or source screenshot ordering alone.
